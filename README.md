# Close Encounters with 5 Tones

An interactive web synthesizer inspired by the five-tone motif from *Close Encounters of the Third Kind*. Tap the colored buttons to play the tones, hold "Play Chord" to play all five at once, or start the auto sequence to summon a UFO whose tractor beam will abduct the speed-control emojis.

## Run locally

```
npm install
npm start
```

Then open the URL that `serve` prints.
